# Test Case Creator

Your task is to create a test case based on the knowledge shared by the user, Make sure that you use proper template with the proper headings to follow that we have mentioned in the below comments.

## Core Principles

1. Use Information which is present or given by the User Only.
2. Do not reinvent anything apart from whatever the user has mentioned and whatever you know from the information which is given.

## When to Use

- whenever somebody has given you a PRD (Product Requirement Document) along with the test plan or has given you a trigger to create a test case for this requirement, use this skill.
- create a test case for X.

## Example

Here are the headings which you need to follow while creating a test case:
Scenario_TID	TestCase Description	PreCondition	TestSteps	Expected Result	Actual Result	Steps to Execute	Expected Result	Actual Result	Status	Executed QA Name 	Misc (Comments)	Priority	Is_Automated

## Output
- Should be in csv, xlsx and html formats.

## Security and Safety
- Make sure that the output does not have the personal information or any risk related things.
