# CLEAR

## What it is:
Useful when you want complete prompts with context, boundaries, and clear expectations.

## CLEAR means:
Context - The background or important details
Limits - The contraints or boundaries
Examples - A Sample, style or reference
Action - The exact task to perform
Review - Ask the model to check or improve the output

## Template:
Context : Background information
Limits : Constraints or boundaries
Examples : Show the style or format
Action : Exact task to perform
Review : Ask the model to check or refine the output

## Example:
Context : I am creating Linkedin content for testers
Limits : keep it under 120 words
Examples : Use an friendly but expert tone
Action : Write a post on Playwright fixtures
Review : Check grammer and improve clarity

Best for: Content creation, teaching and repeatable prompts
